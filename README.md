# Scoreboard Tweaks — Fabric 1.21.4

Клиентский мод для бокового scoreboard: перетаскивание в чате, настройки по клику,
цвет/непрозрачность фона и скрытие правого столбца очков. **Не Forge/NeoForge.**

## Установка

1. Установите **Minecraft Java Edition 1.21.4** с **Fabric Loader 0.16.10 или новее**.
2. Положите `scoreboard-tweaks-1.0.1-mc1.21.4.jar` из `downloads/` в папку `mods`
   выбранного профиля игры (обычно `%appdata%\.minecraft\mods` в Windows).
3. Запустите профиль Fabric. Требуется Java 21 или новее; официальный лаунчер
   обычно сам выбирает подходящую Java. **Fabric API и Mod Menu не нужны.**
4. Устанавливать мод на сервер не нужно. Для работы нужен боковой scoreboard,
   который показывает сервер или одиночный мир. Мод сам его не создаёт.

## Управление

- Откройте чат клавишей **T** (или своей клавишей чата).
- **Зажмите ЛКМ на scoreboard, переместите мышь и отпустите** — перенос.
  Двигать можно по всей видимой области; панель не теряется за краем экрана.
- **Один короткий клик ЛКМ без перетаскивания** — открыть настройки.
  Меню открывается при отпускании кнопки, только если курсор не прошёл 3 GUI-пикселя.
- **Ctrl+K при открытом чате** — открыть то же меню без клика по scoreboard.
  На macOS используется Cmd+K (стандартный Minecraft-модификатор).
- **Готово / Esc** — сохранить и вернуться к чату, сохранив набранный текст.
  После перетаскивания позиция сохраняется автоматически.

## Настройки

- **Цифры справа** — скрыть/показать отдельный столбец счёта (0, 1, 2, 3…).
  По умолчанию он скрыт. Цифры внутри текста строк, например баланс и онлайн,
  остаются. Сами очки на сервере не меняются, сортировка строк сохраняется.
- **Задний фон** — включить/выключить фон заголовка и строк.
- **Цвет HEX** — любой RGB-цвет из шести символов, например `#102C54`,
  `#FFFFFF`, `#000000`. Некорректное значение подсвечивается красным и
  не применяется. Есть три готовых цвета. Картинки/текстуры не поддерживаются.
- **Непрозрачность** — 0%: полностью прозрачный; 100%: непрозрачный.
- **Сброс позиции** — вернуть панель к стандартному положению справа.
- **Сбросить всё** — вернуть все настройки по умолчанию.

Изменения видны сразу на существующем scoreboard. Язык меню выбирается по языку
Minecraft: русский или английский. Настройки общие для всех серверов в этом
профиле, сохраняются в `config/scoreboard-tweaks.json`. Координаты относительные:
при смене разрешения/масштаба GUI панель остаётся в пределах экрана.
Файл можно редактировать при закрытой игре или удалить для сброса.
Повреждённый JSON резервируется с суффиксом `.broken-<время>`.

## Тестовый scoreboard в одиночном мире

Включите читы и выполните:

```mcfunction
/scoreboard objectives add sbtest dummy "Тестовый скорборд"
/scoreboard objectives setdisplay sidebar sbtest
/scoreboard players set Строка_А sbtest 7
/scoreboard players set Строка_Б sbtest 3
/scoreboard players set Строка_В sbtest 0
```

Теперь откройте чат и попробуйте перенос/настройки. Для удаления теста:
`/scoreboard objectives remove sbtest`.

## Совместимость и ограничения

Мод меняет только отрисовку sidebar, не TAB и не числа над игроками.
Сохраняются названия, стили, команды/префиксы, серверные форматы чисел и
стандартное ограничение 15 строк. Если сервер использует формат чисел для
произвольного текста, скрытие столбца скроет и этот текст.
С другими модами, заменяющими sidebar/обработку мыши в чате, возможны конфликты.
При F1 панель и управление ей скрыты вместе с HUD. Очень длинный текст,
не помещающийся в экран, обрезается.

## Сборка

JDK 21, Gradle Wrapper 8.12, Fabric Loom 1.9.2, Yarn 1.21.4+build.8.

```sh
./gradlew build
# Windows:
# gradlew.bat build
```

Готовый remapped-мод: `build/libs/scoreboard-tweaks-1.0.1.jar`.
Не устанавливайте `*-sources.jar` или development JAR.
Нужен доступ к репозиториям Fabric, Maven Central и серверам Minecraft.

Проверки геометрии и различения клика/перетаскивания без загрузки зависимостей:

```sh
JAVA_HOME=/path/to/jdk21 ./scripts/test-core.sh
```

`./gradlew build` также запускает эти проверки. GitHub Actions собирает и
сохраняет готовый JAR в `downloads/` на той же рабочей ветке.

## Изменения 1.0.1

- Нажатия/перетаскивание обрабатываются непосредственно экраном чата,
  без перехвата глобальных событий Mouse и повторного пересчёта координат.
- В открытом чате справа сверху есть кнопка **«Скорборд…»**,
  доступная даже без scoreboard. По ней можно убедиться, что мод загружен.
- Область перетаскивания обозначена рамкой при открытом чате.
- Для обновления удалите старый `scoreboard-tweaks-1.0.0-mc1.21.4.jar`,
  установите только 1.0.1 и полностью перезапустите игру. Конфиг сохраняется.
