# Scoreboard Tweaks 1.1.1 — Fabric 1.21.4

Клиентский мод: перенос sidebar мышью в чате, скрытие правого столбца очков,
палитра цвета фона, непрозрачность и размер 50–200%. Fabric API не требуется.

## Установка / обновление

1. Закройте Minecraft.
2. Установите Minecraft **1.21.4**, Fabric Loader **0.16.10+**, Java **21+**.
3. Удалите предыдущий JAR **Scoreboard Tweaks** из папки `mods` своего профиля.
4. Положите туда `downloads/scoreboard-tweaks-1.1.1-mc1.21.4.jar` и запустите игру.

Конфиг предыдущих версий сохраняется: `config/scoreboard-tweaks.json`.
Не устанавливайте несколько версий этого мода одновременно. На сервер мод
ставить не нужно. Мод изменяет существующий sidebar, а не создаёт его.

## Управление

- Откройте чат **T**, зажмите ЛКМ на скорборде и перетащите его.
- Зона захвата включает всю панель и 6 GUI-пикселей вокруг неё, но **полностью
  невидима**: нет синей/зелёной рамки и всплывающей подсказки.
- Короткий клик без перетаскивания открывает настройки. Они также доступны
  через **«Скорборд…»** справа сверху в чате или **Ctrl+K** (на macOS также Cmd+K).
- **Кнопки «Переместить» и отдельного режима размещения больше нет.**
- **↑/↓** работают с историей сообщений/подсказками как в обычном Minecraft.
  Кнопка «Скорборд…» обрабатывается только мышью и не включена в навигацию
  клавиатурой. Набранный текст сохраняется при возврате из настроек.

## Настройки

- **Цифры** — показать/скрыть правый столбец очков. Числа внутри текста строк
  (например баланс, онлайн) не удаляются; серверные данные не изменяются.
- **Фон** — включить/выключить фон текста и заголовка.
- **Цвет… / образец цвета** — палитра: полоса справа выбирает тон, квадрат —
  насыщенность/яркость. Можно удерживать ЛКМ. HEX-ввод также доступен.
- **Непрозрачность** — 0%: прозрачный; 100%: непрозрачный.
- **Размер** — 50–200%; изменяется только скорборд, а не остальной интерфейс.
  Если панель не помещается на экране, она автоматически вписывается в него.
- **Сброс позиции** / **Сбросить всё** — восстановить положение / все настройки.
- **Готово / Esc** — сохранить. В палитре «Отмена» возвращает исходный цвет.

### Предпросмотр и немедленное применение

В настройках и палитре справа есть отдельная область **«Просмотр»**. Она не
перекрывается кнопками, рисуется независимо от HUD (в том числе при F1) и
пересчитывается из текущих данных и настроек каждый кадр. Цвет, прозрачность,
цифры и размер видны без закрытия меню. Палитра использует градиенты вместо
тысяч отдельных цветных ячеек, что уменьшает объём отрисовки.

Шахматный фон показывает прозрачность. Предпросмотр автоматически вписывается
в выделенное место — на маленьком GUI он может быть меньше игрового скорборда;
это **не меняет** сохранённый размер/позицию в игре. Если сервер убрал sidebar,
показывается «Нет данных», а не устаревшая панель.

## Совместимость

Изменяется обычный Minecraft sidebar, не TAB и не числа над игроками.
Сохраняются стили текста, команды/префиксы, сортировка и лимит 15 строк.
Для сторонних модов, полностью заменяющих sidebar или чат, совместимость
не гарантируется. Если сервер использует столбец очков для произвольного текста,
скрытие чисел скроет и этот текст. Настройки общие для серверов в одном профиле.

## Быстрый тест в одиночном мире с читами

```mcfunction
/scoreboard objectives add sbtest dummy "Тестовый скорборд"
/scoreboard objectives setdisplay sidebar sbtest
/scoreboard players set Строка_А sbtest 7
/scoreboard players set Строка_Б sbtest 3
/scoreboard players set Строка_В sbtest 0
```

Удаление: `/scoreboard objectives remove sbtest`.

## Сборка и тесты

JDK 21, Gradle Wrapper 8.12, Fabric Loom 1.9.2, Yarn 1.21.4+build.8:

```sh
./gradlew build                  # Windows: gradlew.bat build
./scripts/test-core.sh          # без скачивания зависимостей, нужен JAVA_HOME
./gradlew runSmokeClient        # отдельный тестовый мод, нужен дисплей/Xvfb
```

Готовый production JAR: `build/libs/scoreboard-tweaks-1.1.1.jar`.
Тестовый мод `src/smoke/` не входит в распространяемый JAR. CI создаёт реальный
одиночный мир и проверяет клики/перенос через Mouse, масштабы GUI и панели,
палитру, сохранение, историю чата ↑/↓. Проверка предпросмотра читает пиксели
framebuffer после изменения HEX и прозрачности, при смене GUI и открытии
палитры с F1, а не только значения конфигурации. Ручные тесты со сторонними
клиентами/модпаками не проводились.

Полноценная сборка запускается через GitHub Actions из-за сетевых ограничений
песочницы. Готовый JAR возвращается в `downloads/` на текущей рабочей ветке.
Лог: `downloads/smoke-test.log`, контрольные суммы: `downloads/SHA256SUMS.txt`.
